SmartFenix - Documentacion Tecnica

SmartFenix es una aplicacion web y API REST desarrollada con Spring Boot para la gestion de clientes, empleados, proyectos y tareas. La solucion combina interfaz web con Thymeleaf y endpoints REST sobre una arquitectura en capas.

Arquitectura

El proyecto sigue una estructura Controller - Service - Repository - Domain. Para la interfaz web se usan controladores MVC en controller/web y plantillas Thymeleaf en src/main/resources/templates.

Arranque del entorno

Primero se levantan los servicios de infraestructura con Docker Compose:

docker compose up -d

Despues se arranca la aplicacion:

mvn spring-boot:run

Verificacion y pruebas

La documentacion valida del proyecto es la siguiente:

  • Pruebas unitarias con JUnit 5 y Mockito.
  • Las pruebas unitarias no usan base de datos real.
  • La prueba de integracion usa Spring Boot Test, MockMvc y H2 en memoria.
  • La suite completa se ejecuta con mvn test.
  • Docker no es necesario para ejecutar los tests automatizados.
